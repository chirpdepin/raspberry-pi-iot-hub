# Security

## Reporting a vulnerability

Email **info@kiloiot.de** to report a vulnerability in the Raspberry Pi IoT
Hub or its redistributed components. Please do not open a public issue for a
security problem.

Include the affected product version or source revision, a description of the
issue, safe reproduction steps and the potential impact. Do not send
credentials, customer data or sensitive exploit material unless we provide a
restricted channel for it.

CHIRP USA LLC is the manufacturer of the Raspberry Pi IoT Hub software bundle.
The mailbox routes each report to the responsible product and company.

Our machine-readable security contact is published at
<https://kiloiot.io/.well-known/security.txt>.
