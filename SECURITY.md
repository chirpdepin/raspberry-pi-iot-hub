# Security

## Reporting a vulnerability

Email **info@kiloiot.de**. Please do not open a public issue for a security
problem.

It helps if you can include the affected product and version, what the issue
is, how to reproduce it, and the impact you think it has. If you would like
to be credited, tell us the name to use.

Please give us a reasonable opportunity to fix the issue before disclosing it
publicly.

## Scope

This address reaches Kilo (Chirp USA, LLC d/b/a Kilo). Reports about Kilo
hardware, sold by Kilo IoT GmbH / Kilo Electronics, go to the same address and
are triaged to the right company.

Our machine-readable security contact is published at
<https://kiloiot.io/.well-known/security.txt>.
